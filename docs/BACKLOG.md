# BACKLOG

Известные дефекты и что дальше. Закрытое — в истории git.

## parsing

- VLM-разметка для шаблона, загруженного через UI/API: `load_profiles` умеет накладывать кэш, но сам VLM вызывается только из `tools/classify_layouts.py`. Нужно `parse_template(..., vlm=True)` → миниатюры → `refine_with_vlm` для неоднозначных → запись кэша (`parsing/exemplars.cache_payload`).
- Шаблон без единого образца (обложка-картинка, синтетика из сотни фигур) даёт колоду из 0 слайдов без ошибки; в UI нужно внятное сообщение вместо пустого результата.
- Нераспознанные композиции (`freeform`) в `data/wild` — например `presentation_eng_dark` слайды 7–8.

## layout / render

- Пустая карточка лейаута: когда фон карточек и номера «01–04» нарисованы в лейауте, а на слайде лежат `noFill`-прямоугольники, `_remove_empty_containers` лишнюю карточку убрать не может (VK Tech, 3 пункта на 4 карточках). Варианты: parsing помечает такие образцы и picker штрафует `n_items < n_cards` сильнее, либо предпочитать образец на 3 карточки вопреки `REUSE_PENALTY`.
- Нумерация на слайде-продолжении начинается с 1 (кружки «1 2 3», `STEP_NUMBERING`), хотя это шаги 8–12: остатку нужно смещение номеров.
- «Слово» из 300 знаков без пробелов (URL) не переносится и даёт L03; `fitting` мог бы резать по `/`, `-`, `?`.
- 20 data-слайдов в outline при лимите 10 → 22+ слайда: планировщик данные не выбрасывает, только предупреждает; `fit_count` сливает лишь текстовые пары.
- Таблица на chart-образце занимает половину ширины (слот диаграммы), правая половина пуста (D05) — растягивать бокс на область удалённых body-карточек образца.
- KPI на bullets-образце (когда kpi-образца нет) — цифры не крупно.
- Заголовок в «чипе» при 90 % ширины иногда переносится на вторую строку внутри плашки — оценка `0.9·cpl` оптимистична для жирных гарнитур.
- image_text-образец с мокапом устройства: картинка в рамку не встаёт, текст под ним мелкий.
- Картинки генерируются до планировщика: если слайд затем сливается в карточки, отдельная иллюстрация второго слайда пары пропадает (из кэша, повторно не платится).
- Иконки: используются только те, что уже стоят в образцах (`SlotKind.ICON`); своя библиотека (SVG → PNG в цвете акцента) не сделана — на шаблоне без иконок visual их не даёт.
- SmartArt-подобные схемы (process / cycle / pyramid из автофигур) не собираются: `process` только на process-образцах, иначе карточки или список.
- `render/tables.py` не задаёт границы ячеек; в узких таблицах текст ломается по буквам — вопрос ширины table-слота.
- Сокращение тезисов по смыслу через LLM (`skills/slide_filler/v1`) не подключено — работает только детерминированная обрезка.

## audit

- `refine_deck` не перезапускает судью: после фиксов контекстуальные находки помечены `contextual_stale`; в UI можно добавить «Судья ещё раз» (≈30 с).
- Стресс с LLM не делался: странные брифы (пустой, 20 000 знаков, не по теме, другой язык) и замер ≤ 5 мин с судьёй.
- Латентность судьи на целевом инференсе не измерена (на OpenRouter 35–150 с на колоду) — влияет на лимит 5 минут.

## export

- HTML: подписи SVG-диаграммы берут доминирующий цвет текста слайда (`_dominant_text`) — на тёмном фоне с белой карточкой получаются чёрные на тёмном. Брать цвет из `txPr` диаграммы, иначе по яркости фона под боксом. Там же: порядок категорий горизонтальной bar-диаграммы обратный PowerPoint — учитывать `c:orientation`.
- HTML: EOT с MTX-сжатием (`ppt/fonts/*.fntdata`) не распаковывается — встроенный шрифт только через Google Fonts или систему. Вариант: порт MTX-декодера или конвертация через fontTools.

## UI / API

- API: job'ы живут в памяти процесса — после рестарта `GET /jobs/{id}` вернёт 404, хотя файлы на диске есть; восстанавливать из `run.json`.
- Streamlit: прогон блокирует страницу на 1–2 минуты (in-process); при необходимости — фоновый поток + `st.fragment(run_every=…)`.
- `skills/registry.yaml` описывает `agents.deck_generator` с шагами, которые расходятся с фактическим пайплайном (нет images и judge) — привести к факту или убрать блок.
