# AUDIT — проверки сгенерированных слайдов

Аудит — часть пайплайна: `render → audit → autofix → (пользователь выбирает фиксы) → re-render`.
Детерминированные проверки работают по XML .pptx / DeckIR (координаты, цвета, шрифты) и всегда дают один результат.
Контекстуальные — выполняются VLM по PNG слайда (скилл `audit_judge`), результат может отличаться между запусками.

Каждая проверка возвращает `Finding(check_id, severity, slide_idx, element_id, box, message, autofix)`;
`box` подсвечивается в UI, `autofix` — имя функции в `audit/autofix.py`.

## Контекстуальные (`deckforge/audit/contextual/`, скилл `audit_judge@v1`)

Вход — PNG слайда + текст + заголовки соседей + факты из контент-пакета. 11 да/нет вопросов:

| id | Вопрос | Severity |
|---|---|---|
| C01 | Заголовок содержит вывод, а не просто называет тему? | warning |
| C02 | Содержимое слайда соответствует заголовку? | error |
| C03 | Слайд пересказывается одним предложением? | warning |
| C04 | Все цифры и факты со слайда есть в исходных материалах? | error |
| C05 | На слайде есть содержание, а не только заголовок? | error |
| C06 | Картинки и иконки относятся к теме слайда? | warning |
| C07 | Нет служебного мусора: реплик спикера, кусков промпта? | error |
| C08 | Текст без опечаток? | warning |
| C09 | Вся колода на одном языке? | warning |
| C10 | Все строки таблицы и элементы легенды работают на мысль слайда? | info |
| C11 | Соседние слайды связаны между собой по логике? | warning |

## Покрытие тестами

Для каждой детерминированной проверки в `tests/fixtures/` лежит минимальный .pptx с нарушением (генерируется `tests/make_fixtures.py`), и тест `tests/test_audit_<id>.py` проверяет: (а) нарушение найдено, (б) на «чистом» слайде срабатывания нет, (в) после autofix повторный аудит чист.
Контекстуальные проверки тестируются на записанных ответах модели (`tests/cassettes/`).
