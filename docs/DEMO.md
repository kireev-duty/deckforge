# DEMO — сценарий живого прогона и видео-демо (≤ 7 минут, без склеек)

Требование ТЗ: видео-демо до 7 минут — запись экрана без монтажных склеек или живой прогон; на вход — **неизвестный шаблон** и контент-пакет, на выходе — готовая презентация. Тот же сценарий — блок «Демо» в питче (≈ 2 минуты из 7; слайд 9 питча — шпаргалка из пяти шагов).

## Подготовка (до записи, в кадр не входит)

1. `.env` с рабочими ключами; `tools\check_env.py` — все пять пунктов `[OK]` (LLM, VLM, T2I, LibreOffice).
2. Шаблон для демо — чужой, не из датасета: `data\wild\шаблон-макет МТУСИ.pptx` (Montserrat встроен, 41 образец, все архетипы, 0 ошибок аудита на трёх стратегиях) или любой .pptx из интернета. Запасной — `data\wild\02_HSE_Presentation_Shablon_en.pptx`.
3. Прогреть кэши, чтобы в кадре не ждать LibreOffice:
   - один раз загрузить шаблон в UI («Свой шаблон .pptx») — он сохранится как `out\ui\templates\<stem>__<sid>.pptx` и останется в списке «📤» после перезапуска;
   - `.venv\Scripts\python.exe tools\render_deck.py "out\ui\templates\<stem>__<sid>.pptx"` → `out\render\<stem>__<sid>\contact.png` — UI ищет миниатюры образцов именно по stem загруженного файла (`ui/app.py`, `show_template`), рендер `data\wild\…` напрямую не подхватится;
   - `.venv\Scripts\python.exe -m deckforge.cli parse "data\wild\<шаблон>.pptx"` — убедиться, что палитра/шрифты/архетипы осмысленны (это же говорится вслух);
   - сухой прогон целиком с судьёй на этом шаблоне: замерить время (≈ 3 мин) и прогреть `out\archetypes\`.
4. Контент-пакет под рукой в проводнике: `examples\content_pack\brief.md` (текст брифа — в поле), `product.md`, `data\metrics.json` (файлы — в загрузчик). В UI есть чекбокс «Добавить пример „Пульс команды“» — можно им, но загрузка файлов в кадре нагляднее.
5. Запустить UI заранее: `.venv\Scripts\python.exe -m streamlit run deckforge\ui\app.py` → `http://localhost:8501`. Окно браузера 1920×1080, масштаб 100 %, боковая панель открыта. PowerPoint установлен и закрыт.
6. Запись: OBS / Xbox Game Bar (Win+G), один дубль. Таймер на втором мониторе или телефоне.

## Запасные ходы

- **OpenRouter тормозит / таймаут** (судья 40–150 с на колоду днём): снять чекбокс «VLM-судья» — прогон ≈ 1,5 минуты; судью показать на готовой колоде из `examples/output/*/narrative.audit.json` (контекстуальные находки в «Все находки»).
- **LLM не отвечает совсем**: CLI с готовым outline —
  `.venv\Scripts\python.exe -m deckforge.cli run -c configs\run.example.yaml --outline examples\output\vk_tech\outline.json --no-judge --no-images --png -o out\demo` — три колоды ≈ 50 с; показать `out\demo\compare.md` и PNG.
- **LibreOffice не найден**: UI предупредит; без PNG/PDF/судьи — показать .pptx в PowerPoint и .html в браузере (не зависят от LibreOffice).
- **Картинки (T2I)** в UI выключены (`images="off"`) — в кадре о них не говорить или показать `examples/output/vk_tech/visual/` (сгенерированные иллюстрации в `images/`).

## Что должно попасть в кадр обязательно (критерии ТЗ)

1. Загрузка **неизвестного** шаблона и разбор его дизайн-системы.
2. Три варианта на одном контенте.
3. Аудит: детерминированные находки с подсветкой на слайде, контекстуальные (судья), автофиксы и выбор пользователя.
4. Экспорт .pptx с редактируемыми объектами (клик в диаграмму в PowerPoint), .pdf, .html.
5. `manifest.json` с версиями скиллов/моделей и таймингами.
