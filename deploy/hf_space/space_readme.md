# deckforge — цифровой дизайнер презентаций

Демо-стенд сервиса команды deckforge (кейс VK Tech, хакатон «Лидеры цифровой трансформации 2026»).
Сервис читает .pptx-шаблон как дизайн-систему и собирает по нему три варианта колоды нативными объектами,
с аудитом и экспортом в .pptx / .pdf / .html.

Как попробовать: выберите шаблон слева (или загрузите свой .pptx) → режим «Только шаблон» → «Сгенерировать варианты».

Код, документация и 12 готовых колод: https://github.com/kireev-duty/deckforge
